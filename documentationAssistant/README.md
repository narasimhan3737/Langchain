# Documentation Assistant using Langchain

This project aims to build an intelligent documentation assistant using embeddings, vector databases, retrieval systems, and memory management to efficiently search, suggest, and manage technical documentation, enhancing productivity and accuracy in finding relevant information.

---

## Features

- **Intelligent Search:** Leverages embeddings and vector databases for context-aware, semantic search.
- **Contextual Recommendations:** Suggests relevant documentation based on user queries and context.
- **Memory Management:** Stores and recalls previous interactions to provide a more personalized experience.
- **Efficient Retrieval:** Quickly fetches the most relevant documents, reducing time spent manually searching.

---

## Tech Stack

- **Embeddings:** To convert text into high-dimensional vectors.
- **Vector Databases:** For fast and efficient similarity searches.
- **Retrieval System:** Manages document queries and ranks results.
- **Memory Management:** Retains session history for long-term context awareness.

---

## Installation

1. Clone the repository:

    ```bash
    git clone [https://github.com/your-repo/intelligent-doc-assistant.git](https://github.com/narasimhan3737/Langchain.git)
    cd documentationAssistant
    ```

2. Set up a virtual environment (optional but recommended):

    ```bash
    python -m venv venv  
    source venv/bin/activate   # On Windows use: venv\Scripts\activate
    ```

3. Install dependencies:

    ```bash
    pip install -r requirements.txt
    ```

4. Configure your environment variables (e.g., database URL, API keys).
